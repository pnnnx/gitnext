# gitnext (npm)

`gitnext` — git that understands code: a code map and symbol graph for AI agents,
plain-language git for people. This package downloads the prebuilt binary for
your machine (macOS / Linux, x64 / arm64) from the matching GitHub release.

```sh
npx -y gitnext init        # index the repo, write the code map
npx -y gitnext setup       # connect Claude Code / Cursor / Codex
npm i -g gitnext           # or install the command
```

Project and docs: https://github.com/pnnnx/gitnext
